# Vacancy Management

This project was part of my journey learning Java Backend development. I built it to practice Spring Boot and understand how to develop a REST API with database integration, authentication, and security.

During the project, I also had the opportunity to work with AWS, configuring an RDS database and an EC2 instance running Ubuntu. This gave me a first experience deploying and configuring application infrastructure in the cloud.

The project was developed for learning purposes while studying Java and Spring Boot.

## What I Learned

Throughout the development of this project, I was able to practice:

- **Spring Boot:** building REST APIs and working with dependency injection.
- **JPA and Hibernate:** mapping entities, creating relationships, and working with database persistence.
- **Spring Security and JWT:** implementing authentication, token validation, and route protection.
- **Custom Filters:** understanding how authentication filters work in Spring Security.
- **Testing:** working with JUnit and configuring test environments with H2.
- **Swagger:** documenting API endpoints and testing requests.
- **Monitoring:** configuring Actuator, Prometheus, and Grafana to collect and visualize application metrics.
- **AWS:** configuring an RDS database and an EC2 instance with Ubuntu.
- **Docker:** using Docker Compose to run PostgreSQL and monitoring services.
